Game Development

Boards
  • Sudoku board generation using a recursive backtracking algorithm.
  • Random number of empty starting cells within a range based on the selected difficulty.
  • Final board verification to ensure that each puzzle has a unique solution.
Gameplay and assistance
  • Implementation of number entry and deletion, cell selection, and a pencil mode for noting candidate numbers in a cell.
  • Player hint system.
    • Reveal the correct number in the current or a random cell.
  • Configurable visual assistance system.
    • Highlights for blocks, rows, columns, and matching numbers.
    • Error display.
    • Automatic notes of possible numbers in empty cells, based on the numbers already placed in their row, column, and block.
    • A count of numbers to place, showing how many times each number is still needed to complete the board.
Local saving, accounts, and cloud data
  • Google sign-in and guest access through Firebase Authentication.
  • Cloud storage of account data and player progression with Firestore.
  • Local game saving, so players can resume an in-progress game later, along with other supporting data.
Progression, statistics, and customization
  • Implement experience, player levels, and a coin economy.
  • Present the player's progress in a statistics section.
  • Develop a background shop with items that can be unlocked through progression and purchased with coins.
Screen Manager, localization, and audio
  • Implementation of a Screen Manager to control the flow between the game's screens.
  • Download and local storage of localization data.
  • Integration of sound effects and configurable audio settings.
Ads
  • Integration of rewarded ads with Google AdMob.
    • The ad flow still needs full testing. AdMob's app readiness review can begin once the game is published and linked to a supported app store.
  • Consent management with Google's UMP SDK.
