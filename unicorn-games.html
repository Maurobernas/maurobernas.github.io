MY CONTRIBUTIONS

From package review
to mobile delivery.

A repeatable process tailored to each title.

01

ASSESSMENT

Package analysis & acceptance

Before production, I assess each Unity package to evaluate its condition and viability for the planned adaptation.

  • I identify existing gameplay errors.
  • I review the quantity and quality of available levels.
  • I estimate the code changes required for the requested game and level configuration.
02

DATA-DRIVEN LEVELS

Google Sheets → CSV level workflow

I add a system to download the Google Sheet CSV and convert it into an in-game level-data dictionary. The Game Designer can add, remove, and modify levels online; the game downloads the updated CSV, so each game design change does not require a new APK build.

↗Level composition

Each game level can combine selected rounds and levels from the original package.

↗Gameplay parameters

The sheet configures score targets, collectible count and type, time limits, lives, and available power-ups.

↗Word-based games

For word-based games, the sheet replaces the default word list with the selected vocabulary.

03

UNITY IMPLEMENTATION

Gameplay, integration & presentation

I adapt each game in Unity to the client brief and integrate the assets provided by the art team.

  • I fix existing gameplay issues and adjust mechanics when needed.
  • I integrate the company’s Bitel foundation for the map and prize-delivery flow.
  • I apply the art team’s visual changes and integrate the company mascot with animations, dialogue, and sounds.
  • I add a tutorial and, depending on the game, a Bitel power-up.
  • I use timers or lives when the level design requires a completion limit.
  • I organize prize-delivery stages and compress assets to reduce the APK size.
